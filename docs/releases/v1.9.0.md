# Open TTS v1.9.0

This is the largest Open TTS release so far. It adds ElevenLabs-style voice
tools, four new local models, a much more capable Reader and Studio, and faster
streaming, and it rebuilds the app's internals around a typed engine registry.
The Electron desktop app is now the primary product; the web build still ships
but is deprioritized.

## New models

- **Kitten TTS Nano 0.8** (Apache-2.0): a 15M-parameter English model with
  eight voices that runs faster than real time on WebGPU or WASM.
- **Paradee-8M** (Apache-2.0): a 9 MB distilled English voice that starts
  almost instantly.
- **Piper**: eight curated English voices whose whole training lineage is
  public domain, CC0, CC BY 4.0 or Apache-2.0, including the 904-speaker
  LibriTTS voice. Voices download on first use, with progress, and their
  licence and attribution appear in the app and in Credits.
- **Chatterbox Turbo** (MIT, desktop, WebGPU only): zero-shot voice cloning from
  a short WAV clip, with no transcript, plus inline expression tags such as
  `[laugh]` and `[sigh]`. It is slower than real time on an Apple GPU.
- Audio8 and Supertonic 3 accept a seed (Audio8 also a temperature), so a take
  can be repeated exactly.

## Voices

- **Voice Library** (desktop): one searchable catalog of every engine's voices
  and your own, with previews, favorites, saved presets, one-click use in Studio
  or the Reader, and portable `.voice.zip` import and export.
- **Instant voice cloning**: record from the microphone or pick a WAV, trim it,
  get per-engine quality guidance, and save the clone for Qwen3 Base, NeuTTS or
  Chatterbox Turbo. Microphone access is granted to the app itself for audio
  only; every other permission stays denied.
- **Voice Design**: describe a voice, audition three seeded Qwen3 VoiceDesign
  previews, and save the one you like.

## Studio

- **Generation History**: every generation is kept with replay, download,
  reuse settings, favorites and storage limits.
- **Variations ×3**: render seeded takes of the script or a passage and swap the
  chosen take into the timeline.
- **Dialogue mode**: write `Name: line` scripts, cast each speaker to a voice,
  render turn by turn with per-line regenerate, and export with speaker-tagged
  VTT and SRT captions.
- **Creator tools**: one spoken-text pipeline for every engine, with text
  cleanup, opt-in reading of numbers, dates and money, pronunciation
  dictionaries with JSON and W3C PLS import and export, and `[pause 1.5s]` /
  `<break time="1.5s"/>` tags that become exact silences on every engine.
  A preflight view shows the spoken text, passage and pause map, and a
  duration estimate.
- **Export**: FLAC (16 and 24-bit), loudness presets with a true-peak limiter
  and an ACX loudness report, silence trim, padding and fades, readable caption
  cues, and progress with cancel.

## Reader

- Gapless listening: the next section is rendered while the current one plays.
- System media keys and Now Playing with the book, chapter and cover.
- Each book remembers its engine, voice, language, quality and speed, without
  changing Studio.
- Audiobook export of a chapter or the whole book as a chapter-marked MP3 or a
  ZIP of chapter files.
- Colored highlights, and Markdown or JSON export of notes, bookmarks and
  highlights.
- Sentence and paragraph navigation (dock buttons and Shift+arrow keys), exact
  "listen from this word", and keyboard and screen-reader access.
- The "End of chapter" sleep timer now really stops at the end of the chapter.
- Cleaner imports: nested blocks are read once, EPUB covers and languages are
  kept, and PDF running headers, footers and page numbers are removed.

## Performance

- Supertonic 3 now runs on WebGPU (about 7× faster in the browser eval); it
  previously always fell back to WASM.
- Qwen3 streams each decoded batch immediately instead of holding one back,
  audio output warms up on Generate, and a selected Qwen3 model stays loaded for
  up to 30 idle minutes.
- Audio8 generates about 16% faster with a top-k sampler.
- Reader progress is stored as a tiny record instead of rewriting the whole
  book every 750 ms, and unchanged cached audio is no longer re-saved.
- Qwen3 setup no longer re-hashes gigabytes of weights on every profile switch,
  and download progress no longer floods the renderer.

## Fixes

- Supertonic 3 first-time downloads no longer fail on compressed responses.
- Kokoro no longer silently cuts off long passages on WebGPU.
- Pronunciation rules no longer match the wrong words ("US" no longer rewrites
  "us"), and 0.5× playback really plays at 0.5×.
- Changing a Qwen3 setting no longer wipes another engine's audio, and
  changing the Supertonic 2 language no longer poisons the Reader cache.
- Stopping a browser model no longer reloads it.

## Under the hood

A typed engine registry now describes every model, so adding an engine is a
descriptor plus its worker. `SynthesisApp.tsx` went from 2,127 lines to a
130-line shell. `electron/main.ts`, the WebSocket bridge client and the Rust
bridge's `main.rs` are split into tested modules. A shared worker kit with a
soft ABORT backs the browser engines, a native ONNX model framework backs
Audio8, and Electron keeps a bounded diagnostics log. Lint warnings went from 36
to zero, and the test suite grew from 983 to more than 4,200 tests.

## Known gaps

- The real Rust bridge end-to-end test (`electron/rustLocalBridge.test.ts`) runs
  in CI on Linux but has not been run on an Apple Silicon Mac against MLX since
  the bridge refactor.
- Media keys, the microphone prompt and the audiobook save dialog are verified
  by tests but not yet in a signed, packaged build.
- Automatic transcription of clone references (Whisper) is not available yet.
- `phonemizer`, used by Kitten, Paradee and Piper, is installed through
  `kokoro-js` rather than declared directly in `package.json`.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. Developers can build desktop packages locally using the documented
setup and packaging commands. Model weights are downloaded on first use and are
not bundled.
