# Open TTS v1.9.1

This release fixes how the Reader shows imported books, makes the native
bridge build on macOS 27 with the new Xcode, and replaces the long README with
a short overview.

## Reader

- EPUB chapters, HTML files, and web articles whose source wraps paragraphs
  across lines now read as flowing paragraphs. Those wraps were shown and
  spoken as line breaks, leaving single words stranded on their own lines.
  Only `<br>` and preformatted text break a line now. Books imported before
  this release keep their old text until they are imported again.

## Desktop builds

- The Rust build, test, and lint scripts now target the app's minimum macOS
  (26.0), as CI already did. On macOS 27 the Metal compiler otherwise defaults
  to Metal 4.1, whose address-space rules the pinned MLX kernels do not
  compile under, and a locally built package would not run on macOS 26.
- `npm run doctor:desktop` and `npm run setup:desktop` check for Xcode's Metal
  Toolchain, which newer Xcode releases install separately
  (`xcodebuild -downloadComponent MetalToolchain`).

## Documentation

- The README is now a one-screen overview with a single Reader screenshot.
  Full feature, model, settings, shortcut, and import details moved to
  `docs/user-guide.md`; setup, scripts, packaging, and benchmarks moved to
  `docs/development.md`.

## Development checks

The Qwen model download tests wait for the download button to be enabled
before clicking it, so they no longer fail on slow CI runners. The Rust bridge
suite, Clippy, and `electron/rustLocalBridge.test.ts` were run on an Apple
Silicon Mac with macOS 27 and Xcode 27.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. Developers can build desktop packages locally using the documented
setup and packaging commands.
