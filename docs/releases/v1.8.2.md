# Open TTS v1.8.2

This patch release fixes Audio8 generation on current Node.js runtimes and
polishes model, voice, and error handling across Studio and Reader.

## Audio8 reliability

- Audio8 now initializes ONNX Runtime's FP16 tensor representation before the
  native worker creates cached tensors. This avoids zero-byte buffers on
  runtimes that expose `Float16Array` but whose native ONNX binding cannot yet
  consume it correctly.
- The regression is covered by a native tensor test that verifies the expected
  524,288-byte cache allocation.

## Reader and control fixes

- Reader model selections now complete even though the picker is rendered in a
  portal outside the voice-settings panel.
- Desktop model failures and URL-import failures appear once in the Reader's
  relevant recovery surface instead of being duplicated in a global banner.
- Kokoro's voice picker exposes its menu and checked option to assistive
  technology, returns focus when dismissed with Escape, and Supertonic voice
  buttons expose their selected state.
- Creator Toolkit pause sliders use 0.01-second increments, matching all
  built-in preset values exactly.

## Documentation

The README screenshots have been recaptured from the current Electron app for
Studio, Reader, Qwen3-TTS setup, appearance settings, and keyboard shortcuts.

## Distribution

This is a source-only GitHub Release. GitHub provides the repository source as
ZIP and tarball archives; desktop installers are not attached because the
repository does not contain distribution signing or notarization credentials.
Developers can build locally with the documented setup and packaging commands.
