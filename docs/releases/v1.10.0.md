# Open TTS v1.10.0

This release adds a one-command installer for Apple Silicon Macs, moves the
app to Electron 45 and current versions of its libraries, and fixes desktop
builds and locally built packages on macOS 27.

## Install on a Mac

- With Xcode and Homebrew installed, one Terminal command builds the latest
  release and puts Open TTS in Applications:

  ```bash
  curl -fsSL https://raw.githubusercontent.com/cyanxxy/Local-TTS-studio/main/scripts/install-macos.sh | bash
  ```

  It installs only the build tools that are missing. Node, and Rust when
  rustup is not already present, live in the installer's own folder, so a
  system Node, nvm setup, or shell profile is never changed. Running the
  command again updates the app, and `bash -s -- --check` lists what is
  missing without changing anything. The README has a new Install section,
  and `docs/development.md` documents each step.

## Updated libraries

- Electron 45.0, React 19.3, Vite 8.3, Transformers.js 4.3, ONNX Runtime 1.30
  for Node with the matching 1.31 web build, LiteParse 2.17, and Electron
  Builder 26.18.
- Development tooling moved to Vitest 5 and ESLint 10. `eslint-plugin-react`
  does not support ESLint 10, so `eslint-plugin-react-x` replaces it; its
  `no-missing-key` rule keeps the missing-`key` check.
- The native bridge uses RTen 0.27, with its `.rten` model format enabled for
  the pinned NeuCodec encoder, plus current compatible crates.
- TypeScript stays on 6.0 until `typescript-eslint` supports TypeScript 7, and
  `tch` stays on 0.20 with LibTorch 2.7 for the Windows Qwen build.

## Fixes

- Locally built macOS packages (`npm run dist:mac`) launch again on Apple
  Silicon. Flipping the Electron fuses broke the app's ad-hoc signature, so
  macOS killed it at startup; electron-builder now re-signs it.
- Release builds of the Rust bridge work on macOS 27. Stripping build scripts
  and proc macros while targeting macOS 26 produced libraries that macOS 27
  refused to load; they are now left unstripped. The packaged bridge binary is
  unchanged.
- `electron/rustLocalBridge.test.ts` builds with the same environment as the
  Rust scripts, so it compiles MLX's Metal kernels on macOS 27.
- Errors rethrown while parsing bridge messages, downloading models,
  importing documents and URLs, and generating Audio8 or Qwen speech keep the
  original error as their `cause`.

## Removed

- The unused Vercel configuration. The web build is not deployed anywhere; it
  still builds and runs locally with `npm run dev:web`.

## Development checks

Lint, the type checks, the full Vitest suite (including
`electron/rustLocalBridge.test.ts`), the Rust bridge tests, Clippy, the web
build, and the desktop build were run on an Apple Silicon Mac with macOS 27
and Xcode 27. The installer was run end to end there twice, as a fresh install
and as an update, and the installed app launched.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. On a Mac, the installer above builds and installs the app; other
developers can build desktop packages locally using the documented setup and
packaging commands.
