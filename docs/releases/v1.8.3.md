# Open TTS v1.8.3

This patch release improves inference correctness and reliability across Qwen3,
Audio8, Supertonic, Kokoro, and NeuTTS.

## Qwen3 inference

- Match the model's reserved-token mask, minimum output length, language and
  speaker prompts, and instruction embeddings. Unsupported instruction controls
  are hidden for 0.6B CustomVoice models.
- Preserve on-device repetition penalties and the model's generation settings.
- Correct sentence highlighting, CJK section lengths, numeric text splitting,
  and streaming gaps between cloned-voice sections.
- Reject unknown speakers and reference clips longer than 20 seconds with clear
  errors. NeuTTS also rejects oversized clips instead of silently truncating them.

## Other speech models

- Audio8 reports exhausted generation/context limits instead of returning
  incomplete audio as a successful result.
- Supertonic 2 language selection follows generation and retakes, and separates
  cached Reader audio by language.
- Supertonic 3 inserts real silence for configured pauses.
- Kokoro releases model resources when loading times out, including late loads.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. Desktop installers are not attached; developers can build locally
using the documented setup and packaging commands.
