# Open TTS v1.8.0

This release adds Audio8 TTS Preview 0.6B as a fully local desktop voice engine
and tightens the way Open TTS downloads, caches, runs, and packages its native
ONNX models.

## Audio8 local inference

- Audio8 is now available in both Studio and Reader with six pre-registered
  voices: Clara, Iris, Arthur, Mia, Ben, and Sophie.
- The pinned INT4 models run on the CPU through `onnxruntime-node` in a dedicated
  Electron worker thread. Synthesis text and generated audio stay on the device.
- Audio8 produces 44.1 kHz mono audio and exposes its model-specific controls
  directly alongside the shared synthesis settings.

## Verified model cache

- First use downloads the required Audio8 graphs, external weights, tokenizer,
  runtime manifest, and selected voice profile from their pinned upstream
  revisions.
- Every asset is checked against its expected byte length and upstream digest
  before the inference worker loads it.
- Audio8 settings show the total cache location and size, can clear all cached
  revisions safely, and prune superseded revisions after a successful load.
- The optional voice-registration encoder is not downloaded because this
  release supports the supplied pre-registered voices rather than on-device
  voice registration.

## Runtime and packaging efficiency

- `onnxruntime-node` is pinned and overridden to one shared version, preventing
  multiple native ONNX Runtime copies from being installed or loaded together.
- Desktop packages include only the ONNX Runtime binaries for their target
  platform, substantially reducing the packaged native runtime footprint.
- Packaging checks now verify that the required native module is unpacked and
  that unrelated platform binaries are excluded.

## Distribution

This is a source-only GitHub Release. GitHub provides the repository source as
ZIP and tarball archives; unsigned DMG, ZIP app bundles, and Windows installers
are not published. Developers can still build and package the Electron app
locally with the documented desktop build commands.
