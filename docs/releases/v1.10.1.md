# Open TTS v1.10.1

This release fixes Qwen3 on the LibTorch backend used by Windows x64 builds,
corrects the credits for the Qwen3 runtime, and makes the vendored `qwen3-tts`
command-line tool honour `--seed`. Apple Silicon behaviour is unchanged.

## Qwen3 on Windows (LibTorch)

- Every Qwen3 mode (CustomVoice, voice cloning, and VoiceDesign) stopped with a
  `BFloat16 != float` error before producing audio on the LibTorch backend. The
  vendored runtime keeps some activations in bf16 to match MLX numerics, while
  its LibTorch linear layers hold f32 weights, and LibTorch does not mix the
  two in a matrix multiply. LibTorch linear layers now cast their input to the
  weight's dtype. The MLX path does not compile this code and is unchanged.

## Credits

- The README now credits `second-state/qwen3_tts_rs` by Michael Yuan, the Rust
  implementation of Qwen3-TTS and its MLX backend, and the MLX fork by Mario
  Zechner that Open TTS vendors. The fork adds the quantized MLX layers that
  the `mlx-community` 6-bit models need. The Qwen3-TTS credit links the
  `QwenLM/Qwen3-TTS` repository instead of the Qwen organisation.
- The user guide names the Qwen3 model source and licence: `Qwen/Qwen3-TTS-12Hz-*`
  (Apache-2.0), with `mlx-community` 6-bit conversions on Apple Silicon.

## Vendored qwen3-tts-rs

- The `qwen3-tts` CLI accepted `--seed` but printed that the MLX backend
  ignores it. It now seeds sampling just before generation, with the same call
  the bridge already uses for seeded Qwen3 requests. Without `--seed` it
  samples as before. Open TTS does not build or ship this binary.
- `OPEN_TTS.patch` is regenerated from the pinned upstream revision and the
  vendor digest is updated to match.

## Development checks

`electron/qwen3Vendor.test.ts` passes, including re-applying `OPEN_TTS.patch`
to the pristine upstream sources. Every binary in the vendored crate compiles
against LibTorch 2.7, and the changes add no Clippy warnings.

The LibTorch fix was checked on Linux with LibTorch 2.7 on the CPU, using the
pinned official CustomVoice 0.6B, Base 0.6B, and VoiceDesign 1.7B checkpoints.
A small harness made the same streaming calls the bridge makes. Before the fix
all three modes failed; after it each produced speech that Whisper transcribed
word for word, and the same seed reproduced byte-identical audio. The
`qwen3-tts` CLI with `--seed 7` twice wrote identical files, and `--seed 8` a
different one. Not run for this release: the packaged Windows bridge, LibTorch
CUDA, and the MLX build of the CLI.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. On a Mac, the installer builds and installs the app; other
developers can build desktop packages locally using the documented setup and
packaging commands.
