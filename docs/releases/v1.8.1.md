# Open TTS v1.8.1

This maintenance release modernizes the complete web, Electron, and native Rust
toolchain, adds reproducible setup commands, and strengthens desktop packaging
without changing Open TTS's local-first synthesis model.

## Current desktop and web stack

- Electron is updated to 43.4.0, with React 19.2, Vite 8.2, Vitest 4.1,
  TypeScript 6.0, Tailwind CSS 4.3, and Electron Builder 26.15.
- Breaking API changes in Vitest mocks and worker configuration, Vite's
  dependency optimizer, TypeScript's Node module resolution, Electron console
  messages, and native Rust networking and hashing APIs are migrated.
- Dependencies are exact-version pinned and the npm and Cargo lockfiles are
  refreshed around versions that compile and test together. Qwen source, MLX,
  LibTorch, Rubato, and Opus pins remain intentionally unchanged where an
  upgrade requires separate model-parity or native Windows validation.

## Easier, reproducible setup

- `npm run setup:web` installs the exact dependency tree for the browser app.
- `npm run setup:desktop` performs the same clean install, validates Apple
  Silicon macOS or Windows x64, checks the native build prerequisites, and
  prepares the pinned Rust toolchain.
- `npm run doctor:desktop` performs the environment checks without changing the
  installed dependency tree.
- `.nvmrc` selects Node.js 24.19.0, `rust-toolchain.toml` selects Rust 1.97.1,
  and npm 11.17 enforces a reviewed dependency install-script allowlist.

## Native bridge and packaging

- The Rust bridge uses current compatible HTTP, WebSocket, hash, tokenizer, and
  Hugging Face Xet libraries, with download-size and digest checks retained.
- CI now shares the pinned Node and Rust toolchains, runs Clippy for native
  changes, and verifies the exact merged release source before publishing.
- Desktop packaging checks are ESM-based and verify the target-specific ONNX
  Runtime, Sharp, LiteParse, and Rust bridge contents. Signed macOS and Windows
  commands fail closed when required signing or notarization credentials are
  absent.

Electron 43 follows the platform Downloads folder when a file dialog has no
explicit default path. Open TTS accepts that upstream behavior for model-folder
selection, document import, and renderer downloads.

## Distribution

This is a source-only GitHub Release. GitHub provides the repository source as
ZIP and tarball archives; desktop installers are not attached because the
repository does not contain distribution signing or notarization credentials.
Developers can build locally with the documented setup and packaging commands.
