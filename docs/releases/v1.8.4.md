# Open TTS v1.8.4

This release refreshes the Reader and audio player, improves document imports
and background playback, and adds repeatable Qwen3 generation.

## Reader and playback

- Choose paper, sepia, or night page tones, enter a focused reading layout,
  set a sleep timer, and listen to, bookmark, or annotate selected passages.
- Use the reorganized import menu and library, with chapter progress and
  estimated listening time. Wide windows make room for the open library.
- Use the revised player with a playback-speed picker, mobile overflow menu,
  clearer generation errors, and pause support during Studio generation.
- Keep playback progress, word highlighting, saved position, and chapter
  advancement working while the window is hidden or in the background.
- Read Markdown without spoken formatting syntax and import PDF or scanned
  text without treating every printed line as a separate sentence.
- Follow speech with smoother scrolling and word timing that accounts for
  punctuation. Kokoro now respects line breaks and configured pauses.

## Interface and speech models

- Refresh floating controls and menus with glass styling while keeping reading,
  editing, and settings surfaces solid. Respect reduced transparency and
  increased contrast preferences.
- Fix Kokoro browser generation and WebGPU warm-up by loading its browser build
  without rebundling the embedded phonemizer.
- Add optional Qwen3 seeds, dialect-speaker language tokens, and warnings for
  voice-reference clips shorter than three seconds.
- Keep VoiceDesign descriptions separate from CustomVoice style instructions,
  label token limits per passage, and preserve exact highlighting across long
  requests after IPC and native text trimming.

## Release checks

CI now enforces the configured coverage thresholds, checks the pinned Node
version and Node 26, and runs Linux bridge integration separately. Workflow
actions are pinned and receive weekly dependency update checks.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. Developers can build desktop packages locally using the documented
setup and packaging commands.
