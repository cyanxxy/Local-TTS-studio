# Open TTS v1.8.5

This release fixes interrupted Reader playback, preserves Qwen model choices,
and makes local model shutdown and cache clearing reliable.

## Reader and Qwen settings

- Advance to the next Reader section only after synthesis has completed.
  Interrupted and older cached audio stays playable without skipping unread
  text or marking the section fully read.
- Include the Qwen sampling seed and model directory in Reader audio cache
  identity so changing either setting cannot restore a different take.
- Preserve manually selected Qwen model folders through setup refreshes and
  profile switches.
- Prefer word boundaries when splitting long Qwen passages.

## Desktop runtimes

- Prevent canceled WebSocket requests from starting replacement workers during
  shutdown.
- Cancel and join active generation, warm-up, model discovery, and downloads
  before deleting a model cache. New requests wait until deletion finishes.
- Release the previous NeuTTS backend before switching models, allowing Nano
  and Air to share a resident worker safely.
- Restore standard application, editing, and window menus in packaged macOS
  builds, including native editing shortcuts.

## Development checks

Regression tests cover cancellation, cache deletion, Reader completion,
settings, and native backend replacement. `npm run test:rust:policy` runs the
model-free Rust lifecycle, text splitting, and sampling checks without MLX,
Metal, LibTorch, or model downloads; CI runs this suite as well.

## Distribution

This is a source-only GitHub Release. GitHub supplies ZIP and tarball source
archives. Developers can build desktop packages locally using the documented
setup and packaging commands.
